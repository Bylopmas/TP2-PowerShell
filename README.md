
# Trabajo Practico 2 - PowerShell

**Materia:** Programacion para Seguridad Informatica  

## Descripcion

Este repositorio contiene los ejercicios correspondientes al Trabajo Practico 2, realizados utilizando PowerShell.

## Ejercicio 1: Saludo personalizado

El programa solicita al usuario que ingrese su nombre por consola y luego muestra un mensaje de saludo personalizado.

**Archivo:** `ejercicio1.ps1`

## Ejercicio 2: Calculo de la paga

El programa solicita la cantidad de horas trabajadas y el coste por hora. Luego calcula y muestra la paga correspondiente.

**Archivo:** `ejercicio2.ps1`

## Tecnologia utilizada

- PowerShell
- Windows

## Ejecucion

Para ejecutar cada programa desde PowerShell:

```powershell
.\ejercicio1.ps1
```

```powershell
.\ejercicio2.ps1
```
